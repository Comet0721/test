# 腾讯云秒杀抢购工具 · 简易使用教程

> 解压即用，无需安装任何软件（已内置 Node.js + 浏览器驱动）。

## 一、启动

双击 `start.bat`，自动弹出浏览器打开控制台：`http://127.0.0.1:8790`
（第一次启动若提示防火墙，允许即可）

## 二、添加账号（每台电脑/每个号操作一次）

1. 切到「账号」页
2. 输入备注名（自己好认就行，如：小号1）
3. 点「开始扫码登录」→ 会弹出 Edge 浏览器 → 用微信/QQ 扫码登录
4. 登录成功后自动保存 cookie，窗口自动关闭
5. 多个账号重复以上步骤（每个号一次）

> 命令行方式：`run-login.cmd 小号1`（每个账号跑一次）

## 三、抢购配置（推荐参数已内置，一般不用改）

抢购页配置说明：

| 配置 | 推荐值 | 说明 |
|---|---|---|
| 目标商品 | 4核4G3M | 活动页商品名或 act_id |
| 提前开抢毫秒 | 50 | 开抢前 50ms 发出请求 |
| 抢购区域 | 1 | 1=广州 4=上海 8=北京（多区用逗号，如 1,4） |
| 最大重试次数 | 30 | 开抢后重试次数 |
| 重试间隔 ms | 500 | **别低于 300**，太快要被限流 |
| 波浪每批账号数 | 4 | 账号多时自动分批错峰 |

改完点「💾 保存配置」→ 配置写入后端，刷新不丢。

## 四、开始抢购

1. 「场次」页点「刷新场次」看开抢时间
2. 「抢购」页勾选要参战的账号
3. 点「▶ 启动监控/抢购」
4. 「日志」页看结果：出现「下单成功」= 抢到；出现「限流」会等 2-4 秒自动重试

## 五、常见问题

**Q: 显示「系统繁忙/访问频繁/系统访问频率过快」？**
A: 是 IP 被腾讯临时限流。原因通常是：重试间隔太短（<300ms）、多区并发、账号太多。
解决：用推荐参数（500ms + 单区域 + 30次）；换网络（手机热点流量）；等 15-30 分钟自动恢复。

**Q: 提示「不满足新用户条件」？**
A: 该账号实名主体已买过/领过活动产品，腾讯只给新用户。换没用过的账号（每个实名主体限一次）。

**Q: 开抢时间没到，按钮/请求提示「秒杀尚未开始」？**
A: 正常，还没到点。到点后脚本自动开抢。

**Q: 扫码登录时提示 JSON 解析错误？**
A: 用的是旧版分享包，请换本版（login-capture 已修复并支持批量）。

**Q: 如何知道 cookie 还有没有效？**
A: 「账号」页点「🔍 检测Cookie有效性」，失效的账号重新扫码。

## 六、重要安全提醒

- `accounts.json` 里存的是你的登录凭证（cookie），**不要发给任何人**，别人拿到能登录你的腾讯云
- 分享给别人的是这份**不带任何账号**的干净包，对方要自己扫码添加自己的账号
- 不要用同一个账号在同一秒杀场次反复下单，容易被风控

## 七、进阶（可选）

- `run-sniper.cmd`：命令行直接抢（等价界面点开始）
- `node browser-sniper.cjs --accounts 备注名 --parallel 2`：方案B浏览器代抢（真实浏览器环境，降低风控识别），独立日志 browser-sniper-log.txt
- 多账号：账号页可给每个账号单独勾选区域（不勾=跟随全局区域）
